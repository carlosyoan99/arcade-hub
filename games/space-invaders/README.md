# 👾 Space Invaders

**Versión:** 1.1.0 | **Género:** Space Shooter | **Última actualización:** 2026-07-28

Destruí oleadas de invasores espaciales antes de que lleguen a la base. Escudos, nave misteriosa y velocidad progresiva.

## Controles

| Dispositivo | Acción | Tecla / Control |
|-------------|--------|-----------------|
| ⌨️ Teclado | Mover izquierda | `←` / `A` |
| ⌨️ Teclado | Mover derecha | `→` / `D` |
| ⌨️ Teclado | Disparar | `Espacio` |
| ⌨️ Teclado | Empezar / Reiniciar | `R` |
| 🎮 Gamepad | Movimiento | Stick / D-pad |
| 🎮 Gamepad | Disparar | Botón A |
| 👆 Táctil | Botones en pantalla | |

## Características

- 👾 Invasores que se mueven en formación y aceleran
- 🛡️ Escudos protectores que se deterioran con los disparos
- 🛸 Nave misteriosa que cruza la pantalla (puntos extra)
- ⚡ Disparos enemigos que aumentan con el nivel
- 🏆 Récord persistido en `localStorage`
- 🎮 Soporte para teclado, táctil y gamepad
